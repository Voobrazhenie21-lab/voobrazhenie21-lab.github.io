🛡️ 2. СЗИ: NGFW, IDS vs IPS, DLP, SIEM СЗИ
  • NGFW vs Обычный: Обычный = L3/L4 (только IP и порты). NGFW = L7 с технологией DPI (глубокий анализ пакетов): видит реальное приложение (SSH внутри 443), привязка к Active Directory (User-ID), встроенный IPS и SSL-расшифровка.
  • IDS vs IPS:
    • IDS (Камера): пассивно на зеркале (SPAN-порт), видит копию, шлёт алерт в SIEM (не блокирует).
    • IPS (Шлагбаум): активно в разрыв (In-line), трафик идёт сквозь него, сам сбрасывает (Drop) атаку.
  • DLP (Утечки изнутри наружу): Контроль 4 каналов: почта, мессенджеры/Telegram, USB-флешки, принтеры. Анализ по словарям/регуляркам (паспорта, карты), цифровым отпечаткам и OCR. При сработке: блокируем $\rightarrow$ собираем улики в тишине $\rightarrow$ эскалируем СБ/руководству (не звонить сразу юзеру!).
  • Источники в SIEM: Серверы = Агент (Wazuh). Сетевые железки = безагентно по Syslog (порт 514).
  • Сработка в 03:00 ночи (False Positive): Это наш плановый скрипт бэкапа или сканер уязвимостей $\rightarrow$ чиним пароль или добавляем IP в Whitelist (исключения) правила.
🏢 3. Модель OSI (Мнемоника) & VLAN L1–L7
Мнемоника (сверху вниз 7 $\rightarrow$ 1):
«Алексей Пошёл Сегодня Тренировать Сетевые Компьютерные Фундаменты»
  • 7. Прикладной (Application): HTTP, DNS, DHCP, SSH, SMB + тут фильтрует NGFW.
  • 6. Представления (Presentation): TLS/SSL, UTF-8, JSON (шифрование и кодировка).
  • 5. Сеансовый (Session): RPC, NetBIOS (управление сеансом).
  • 4. Транспортный (Transport): TCP, UDP + номера портов.
  • 3. Сетевой (Network): IP-адреса, пакеты + Роутер (Маршрутизатор), ICMP (ping).
  • 2. Канальный (Data Link): MAC-адреса, кадры + Свитч (Коммутатор), ARP, STP.
  • 1. Физический (Physical): Кабели, радиоволны, биты (0 и 1).
  • 🔥 Ethernet, Wi-Fi, Bluetooth: живут на 1-м и 2-м уровнях (1 = кабель/радио, 2 = MAC и кадры).
  • 🔥 VLAN (802.1Q): живёт СТРОГО на 2-м уровне (свитч делит подсети, тег 4 байта).
🌐 4. Сетевые сервисы (DORA, ARP, TCP) L2/L4
  • TCP 3-Way Handshake: SYN $\rightarrow$ SYN-ACK $\rightarrow$ ACK.
    • SYN Flood DoS: шлют миллионы SYN, не шлют ACK $\rightarrow$ переполнение памяти. Защита: SYN Cookies.
  • DHCP (DORA, UDP 67/68):
    • Discover (клиент ищет) $\rightarrow$ Offer (сервер предлагает) $\rightarrow$ Request (клиент берет) $\rightarrow$ Ack (сервер закрепил).
    • Rogue DHCP: фальшивый сервер раздает хакера как шлюз (MitM). Защита: DHCP Snooping.
  • ARP (IP $\rightarrow$ MAC): Нет аутентификации $\rightarrow$ ARP Spoofing (MitM). Защита: DAI (Dynamic ARP Inspection) + DHCP Snooping.
  • DNS (порт 53): Имя $\rightarrow$ IP. Записи: A, AAAA, CNAME, MX, TXT (SPF/DKIM/DMARC). Атаки: AXFR (дамп зоны), DNS Tunneling (C2).
  • NAT: Перевод серых IP в белые. PAT — через порты для всей сети.
💻 5. Журналы Windows & Linux Event IDs
  • Event ID 4625 $\rightarrow$ Неудачный вход (ошибка пароля / брутфорс).
  • Event ID 4624 $\rightarrow$ Успешный вход:
    • LogonType 3 = вход по сети / SMB (Pass-the-Hash).
    • LogonType 10 = вход по RDP (удаленный стол).
  • Event ID 4769 $\rightarrow$ Запрос билета TGS: шифр 0x17 RC4 = Kerberoasting.
  • Event ID 4768 $\rightarrow$ Запрос TGT: PreAuthType=0 = AS-REP Roasting.
  • Defender 5001 $\rightarrow$ Отключение защиты в реальном времени!
  • Sysmon Event ID 10 $\rightarrow$ Доступ к памяти lsass.exe (дамп паролей Mimikatz, маска 0x1010).
  • Linux: входы SSH $\rightarrow$ /var/log/auth.log; хэши паролей $\rightarrow$ /etc/shadow (только root).
🚨 6. Алгоритм расследования инцидента (5 шагов) SOC
  • 1. Триаж: проверка логов (True vs False Positive).
  • 2. Обогащение: проверка хэша и внешнего IP на VirusTotal, смежные логи.
  • 3. Изоляция (Containment): отключить хост от сети, заблокировать юзера в AD и IP на NGFW.
  • 4. Ликвидация: удалить вирус, сбросить пароль, накатить патчи.
  • 5. Компенсирующие меры: если уязвимый сервер нельзя сразу обновить:
    • Виртуальный патчинг на IPS / WAF (резать атаку на подлёте).
    • Сетевая изоляция (VLAN / ACL / VPN + MFA) (доступ только доверенным админам).
    • Усиленный мониторинг в SIEM (правила FIM и высокий приоритет).
⚖️ 7. Законы РБ & Сканеры уязвимостей Плюс
  • Закон РБ № 99-З «О защите персональных данных»: Регулятор — НЦЗПД. При утечке данных уведомить НЦЗПД в течение 3 рабочих дней!
  • Указ Президента РБ № 40 «О кибербезопасности»: Создание и работа центров кибербезопасности (SOC) во взаимодействии с ОАЦ.
  • Сканеры (Nessus / OpenVAS):
    • Снаружи (без учётки): только открытые порты и баннеры версий (много False Positives).
    • Изнутри (с учёткой SSH/WMI): заходит в ОС, проверяет реальные патчи и реестр (в разы точнее!).
